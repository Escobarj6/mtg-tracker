# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/Escobarj6/mtg-tracker/security/advisories/new).
Include steps to reproduce and the potential impact.

I'll acknowledge reports as soon as I can and keep you updated on a fix.

## Supported versions

This project is in early development. Only the latest code on `main` is supported.
